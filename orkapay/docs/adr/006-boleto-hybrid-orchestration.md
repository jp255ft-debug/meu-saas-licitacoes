# ADR 006: Boleto Hybrid Orchestration

## Decisão
Não substituir o boleto, mas orquestrar a transição híbrida (boleto + Pix).

## Contexto
Boleto ainda representa 69,3% do valor financeiro B2B.

## Motivação
- O mercado B2B não está pronto para abandonar o boleto
- Oportunidade de ser a "ponte" entre o analógico e o digital
- Boleto Híbrido com QR Code Pix já é permitido pelo BC

## Consequências
- Manutenção de dois fluxos (boleto e Pix)
- Maior complexidade de integração com ERPs
