# System Patterns - OrkaPay

## Padrões Adotados
1. **Clean/Hexagonal Architecture**: Domínio isolado, adaptadores plugáveis
2. **Event Sourcing**: Eventos imutáveis como fonte da verdade
3. **CQRS**: Separação entre leitura e escrita
4. **Repository Pattern**: Abstração de acesso a dados
5. **Factory Pattern**: Criação de agregados complexos
6. **Adapter Pattern**: Plugabilidade de BaaS
