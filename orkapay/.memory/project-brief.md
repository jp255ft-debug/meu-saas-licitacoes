# Project Brief - OrkaPay

## Visão Geral
OrkaPay é uma plataforma de orquestração de pagamentos B2B que conecta o mundo analógico do boleto ao digital do Pix.

## Objetivos
1. Reduzir custos de transação em 50-90% para clientes
2. Automatizar conciliação com ledger imutável
3. Oferecer cashback e revenue share para clientes
4. Capturar mercado B2B (menos de 10% digitalizado)

## MVP
- Foco em Cash-In (recebimentos via Pix)
- Integração com Asaas e Stark Bank
- API RESTful com NestJS
- Core em Go com Event Sourcing
